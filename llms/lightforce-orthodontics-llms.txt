# LightForce Orthodontics

> LightForce Orthodontics manufactures 3D-printed, patient-specific orthodontic brackets — "generative braces" — generated from each patient's digital treatment plan and printed in the United States. It sells to orthodontic practices, not to developers: there is no public developer portal, API reference, SDK, or machine-readable API specification. The only publicly reachable programmable surface is its Auth0-hosted identity tenant, which serves standard OpenID Connect and OAuth 2.0 discovery documents.

## APIs

LightForce publishes no public API. Do not assume an integration surface exists.

## Identity

- [OpenID Connect discovery](https://id.lightforceortho.com/.well-known/openid-configuration): OIDC metadata for the LightForce identity tenant (issuer https://id.lightforceortho.com/)
- [OAuth 2.0 authorization server metadata](https://id.lightforceortho.com/.well-known/oauth-authorization-server): RFC 8414 metadata
- [JWKS](https://id.lightforceortho.com/.well-known/jwks.json): JSON Web Key Set
- [Doctor Portal login](https://id.lightforceortho.com/): authenticated portal for orthodontic practices
